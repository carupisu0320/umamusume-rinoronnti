# ウマ娘 理論値計算エンジン（プロトタイプ）

サポートカード編成と練習回数から、育成終了時のステータス理論値を試算するツールです。
現時点では計算エンジンのプロトタイプ段階で、最適化アルゴリズムやデータ自動収集は未実装です。

## できること

- サポートカード編成（6枠）の入力・編集
- 施設ごとの単発練習シミュレーション（練習効果・友情ボーナス・得意練習ボーナス・やる気を反映）
- 育成プラン全体の理論値概算
- 編成・プラン入力の保存/読み込み（Claudeのアーティファクトとして開いた場合はクラウド保存、それ以外はJSONファイルの書き出し/読み込み）

## 使い方

`index.html` をブラウザで直接開くだけで動作します。ビルドや依存関係のインストールは不要です。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で `main` ブランチ / ルートディレクトリを指定してください。

## データについて

基礎トレーニング値は [神ゲー攻略](https://kamigame.jp/) のグランドライブシナリオのデータを参考にしています（やる気普通・成長率なし基準、主ステータスのみ反映）。ゲーム内のステータス名・数値等のゲームデザインに関する情報を参考にしていますが、サイトの文章や画像を複製するものではありません。「ウマ娘 プリティーダービー」の著作権は株式会社Cygamesに帰属します。本ツールは非公式のファンメイドツールです。

友情ボーナスの正確な倍率、副ステータスの同時上昇、シナリオごとの基礎値の違いなど、未反映の要素があります。
